# 放送時刻変更の取り込み

EIT p/f actualを優先し、scheduleの古い時刻で上書きしないようにしています。
p/fだけの取得でも出力し、開始・終了不明の番組は確定時刻として出力しません。
同一テーブルのバージョン更新と31→0の周回、current_next、event_id=0に対応します。
同時刻の別イベントを保持し、予約済みイベントの識別子を維持できるようにします。

以下のテストは一時ディレクトリでビルドし、チューナーやインストール先にはアクセスしません。
内部のEIT解析と、CRCが正しい合成TSを実コマンドに渡した結果の双方を検証します。

```sh
sh tests/run_follow.sh
SANITIZE=1 sh tests/run_follow.sh
```
